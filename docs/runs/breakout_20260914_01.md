The CUDA evaluator requested 256 episodes; batched completion produced 265.
The trainer's final same-seed evaluation score was 394.1362. The CPU evaluator
uses a separate environment implementation and does not apply its seed CLI
setting. Its score is a playback sanity check, not a matched backend comparison.
The no-checkpoint CPU baseline uses NOOP actions, not random actions.

The training dashboard rose from score 10.853 near 16.8M steps to 707.282 at
54.9M steps. These are training rollout scores; the separate frozen-checkpoint
CUDA score above is the evaluation result. One training seed is not evidence
of robustness. The GPU had other active workloads, so this is not an isolated
throughput benchmark. Build time is excluded from both times in the table.

## Validation

- Breakout and Minimal compiled with ASan/UBSan and completed 1,024 headless
  steps each on both macOS arm64 and Linux x86_64.
- All saved metric samples, including loss series, and all checkpoint weights
  are finite. The launch process exited 0.
- Checkpoint architecture matches the CPU viewer: 16,192 float32 weights.
- SHA-256 matched after transfer to the Mac:
  `868fb8b97a85946141bdc4a50b2e6bd20b0d9be3c4df114aaa1fb2aed95f08d4`.
- The native Mac viewer initialized OpenGL, shaders and textures successfully
  and was left running with this checkpoint. UI automation could not select
  the unbundled executable; window contents were not captured through that tool.

## Reproduce

From the repository root on the GPU machine:

```sh
./scripts/train_breakout.sh breakout_NEW_UNIQUE_ID
```

Exact first-run command and full measurements are in
[the JSON report](breakout_20260914_01.json). Resolved configuration and raw logs
remain under ignored `outputs/breakout_20260914_01/` on the two workstations.
The repo source was synchronized through a small Git bundle while the first
GitHub push packaged upstream history; the recorded source commit is identical
on both machines and is now on `origin/main`.

Download the preserved policy from the repository release:

```sh
mkdir -p outputs
gh release download breakout-baseline-20260914 --repo rozgo/alienwars-gym \
  --pattern breakout-demo.bin --dir outputs
./scripts/play_breakout.sh outputs/breakout-demo.bin
```

The current local checkout already has `outputs/breakout-demo.bin`. Escape
closes the viewer. Hold Left Shift plus Left/Right (or A/D) for human control.
Use the release tag's `config/breakout.ini` with these weights. The `.bin`
contains policy weights only, not an optimizer-resume snapshot.
