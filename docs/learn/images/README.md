# Sensor lesson screenshots

Captured from the published Map Lab in Chrome on 2026-09-18, at commit
`a5925f1b7b114c943220b71826a23455aa6d5f0f`.

The scene uses seed 73, symmetric layout, base floors 6/6, temperate terrain,
tunnels enabled, automatic cutaway and heavy submarine 11. The camera is focused
on that submarine. Patrol traffic is paused to hold its position while comparing
the overlay and equipment controls. The images show actual application states;
the readouts have not been edited. PNG browser captures were encoded as WebP.

- `sonar-visible.webp`: overlay on, sonar attached, valid reading.
- `sonar-hidden.webp`: overlay off, sonar attached, valid reading.
- `sonar-detached.webp`: overlay on, sonar detached, “Not attached” readout.
