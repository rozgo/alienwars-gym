From GPU training to your browser

This policy was trained on an NVIDIA RTX 4090 with PufferLib 5. The training loop took 1.98 seconds; initialization and final evaluation brought the process to 3.30 seconds. These are measurements from one run on a shared GPU.

You are watching live inference with fixed, learned weights. The browser advances the Breakout simulation and chooses actions using WebAssembly; Raylib draws the game through WebGL. No training or video streaming happens on this page.

This is the upstream Breakout baseline for AlienWars Gym. A separate GPU evaluation averaged 391.9 points across 265 completed episodes. Browser behavior uses the CPU environment implementation and is not a matched GPU benchmark.
